==================================================
PROJECT GOAL
==================================================

Build the production-ready foundation of PostFlow Bot.

The final application will monitor Telegram channels that the authorized Telegram USER ACCOUNT has access to, process channel content, optionally clean configured attribution/usernames/links, and publish the processed content to configured destination channels.

The system will have TWO separate Telegram connections:

1. TELETHON USER ACCOUNT
2. TELEGRAM ADMIN BOT

==================================================
IMPORTANT TELEGRAM ARCHITECTURE
==================================================

TELETHON USER ACCOUNT:

Telethon must connect using:

- API_ID
- API_HASH
- TELEGRAM_SESSION

This connection represents the authorized Telegram USER ACCOUNT.

It will eventually be responsible for:

- Monitoring source channels
- Reading channel messages
- Resolving channels
- Processing incoming content
- Publishing content to destination channels

Do NOT use the Bot Token for the Telethon user connection.

--------------------------------------------------

TELEGRAM ADMIN BOT:

The Admin Bot must connect using:

- BOT_TOKEN

It will be responsible for:

- Admin control panel
- Source channel management
- Target channel management
- Routing configuration
- Settings
- History
- System status

Do NOT use API_HASH as the Bot Token.

==================================================
TELEGRAM CONNECTION ARCHITECTURE
==================================================

                    TELEGRAM
                       |
             +---------+---------+
             |                   |

      TELETHON CLIENT       ADMIN BOT

     + USER SESSION               |
             |                   |
             v                   v
     Telegram User          Admin Control
        Account                  Panel
             |

      Source Channels
