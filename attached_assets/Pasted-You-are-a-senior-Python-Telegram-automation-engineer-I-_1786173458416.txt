==================================================
PROJECT GOAL
==================================================

Build the foundation for a Telegram content reposting system.

The final system will monitor Telegram channels that the authorized user account has access to, process incoming channel posts, remove configured attribution/usernames/links from the content where permitted, and publish the processed content to configured destination channels.

IMPORTANT:

==================================================
CORE ARCHITECTURE
==================================================

The project will have TWO Telegram components:

1. TELETHON USER CLIENT
2. TELEGRAM ADMIN BOT

Telethon User Client:
- Used for monitoring channels accessible to the authorized Telegram account.
- Will eventually receive new channel posts.
- Will eventually process and publish content.

Telegram Admin Bot:
- Used by the administrator to control the system.
- Will eventually manage source channels, destination channels, rules, history, and settings.
