==================================================
ADD SOURCE CHANNEL
==================================================

When admin presses:

➕ Add Source

Ask:

"📡 Send the Source Channel username or Channel ID."

Accept:

@channelusername

or

channel username without @

or

numeric Telegram Channel ID where supported.

Example:

@examplechannel

After receiving the input:

1. Validate the input.
2. Use Telethon to resolve the channel.
3. Confirm that the Telegram account can access the channel.
4. Retrieve:
   - Telegram Chat ID
   - Username
   - Title
   - Channel type
5. Store the channel in the database.
6. Prevent duplicate entries.

If successful:

"✅ Source Channel added successfully."

Show:

📡 Source:
Title: Example Channel
Username: @examplechannel
ID: -100xxxxxxxxxx
Status: 🟢 Active

Do NOT expose unnecessary Telegram internal information to users.

==================================================
